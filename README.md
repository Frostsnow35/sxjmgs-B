## 协作约定

1. 分支命名：`feature/<topic>`、`fix/<topic>`、`docs/<topic>`。
2. 提交信息：使用 `feat:`、`fix:`、`docs:`、`test:`、`chore:` 前缀。
3. 不提交密码、Token、个人手机号、模拟器运行数据库或正式测试日志中的敏感内容。
4. 修改公式、算法、参数或评价口径时，同步更新模型说明和 `state/decision_log.json`。
5. 结果必须从代码、输入和日志溯源；未经用户确认的方案不得标记为最终方案。

## 重要测试门禁

问题 3、问题 4 正式测试各只有 3 次机会，手工中止也会消耗机会。问题 4 正式测试必须得到用户当次明确批准；任何脚本、HTTP 请求或 UI 自动化都不得绕过该门禁。
