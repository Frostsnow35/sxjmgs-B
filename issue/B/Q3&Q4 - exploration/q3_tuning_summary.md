# Q3 提速调优小结

日期：2026-09-11

## 已测试变量

| 变量 | 结论 |
| --- | --- |
| `min_signals` 巡测停扫阈值 | **2 最优**；1 和 3 均更慢 |
| Q3 安全负距离约束（全部 `no_signal`） | 当前实现不划算，额外采样与试探清除开销超过收益，默认关闭 |
| MEC 半径 `20<R≤25 m` 原位试探清除 | 有益，已保留 |
| 巡测路线 | 正六边形路线长度 9353.074 m，已等于 MST 下界；数值搜索可得到约 8411 m 的非正六边形点集，但覆盖余量从 100 m 降到接近 0，稳健性差，暂不采用 |
| 六边形巡测方向 | 顺时针方向（`v0→v5→v4→v3→v2→v1`）比自然逆时针方向平均快约 28 s，已采用 |
| 六边形外环半径 | 从 `900√3≈1558.8 m` 缩短为 **1124 m**；最大覆盖空隙由 900 m 增至 999.545 m，仍小于 1000 m，但巡测路线从 9353 m 缩短到 6744 m，平均节省约 500 s |
| 原位试探清除阈值 | 从 25 m 提高为 80 m；小半径巡测下平均更快 |
