## A 题：定日镜场的优化设计
1. **linggm3/2023_CUMCM_National-First-Prize**（GitHub，含论文《定日镜场优化设计模型》、代码、支撑材料、答辩 PPT）——【全文思路可读（README 逐节详述）】自述本科组**全国一等奖**。路线：由太阳高度角/方位角/赤纬角构造入射-反射光线与镜面法向矢量模型 → 用**二维正态分布**描述太阳光锥能流密度、构造偏移向量 → **蒙特卡洛光线追迹**按到达吸热塔中心的光线占比算截断效率 → 参考 Campo 法提出**同心圆密排布局**压缩自由度 → 建立**双层规划**（上层定吸热塔位置，下层优定日镜参数，循环迭代反馈）→ 问题三放开自由度，按"远塔镜高、近塔镜小、近密远疏"优化。
2. 官方解析《定日镜场的优化设计》（国防科技大学 王丹、吴孟达、毛紫阳），《数学建模及其应用》2024,13(01):30-43 ——【仅有摘要】命题背景、光学效率计算模型、阴影遮挡与截断发生判定条件、镜场部分参数讨论。
3. 同卷期刊精选获奖论文（摘要级，奖项/队伍未在页面标注）：《定日镜场的最优参数选择》（官思扬、方俊杰、辜榆帆，张勇）——**栅格化**离散镜面算阴影遮挡/截断效率，**单目标优化+控制变量法降维**（试算功率-变量曲线），**0.618 法（黄金分割）一维搜索**极值；另有《定日镜场在额定输出功率条件下的光学效率优化》《定日镜场光学效率的计算模型》《基于目标规划的定日镜场设计》（01 期 .06–.08）——仅见题名，未见正文。

## C 题：蔬菜类商品的自动定价与补货决策
1. **最高奖核实**：复旦大学 曹宇轩（经济学院）、黄瑞、秦一天（管理学院）获 2023 年本科组唯一最高奖"**高教社杯**"（复旦新闻网 2023-11-28，复旦 32 年首捧杯；该校另有国一 1 项、国二 10 项）。
2. 该队论文《基于历史数据的蔬菜类商品定价与补货决策模型》刊于《数学建模及其应用》2024,13(02):37-46 ——【摘要可读】+ 博客园逐节学习笔记 [yjbjingcha/p/19032617]【部分正文转述可读，含问题一细节】。技术路线：流水缺失/异常值（四分位距法）清洗并按单品/品类汇总 → 问题一用 **K-S 检验**（两两 15 次）判别品类销量分布异同、**皮尔逊相关**热力图、**ARIMA** 拟合日销量、周/月/年规律热力图，取销量占比≥1% 的 31 个单品做相关+聚类 → 问题二用 **Prophet** 拆趋势/季节/节假日成分、售价作外生变量，建品类销售额-成本加成率关系，**模拟退火+遗传算法**迭代求最优定价补货 → 问题三加入库存空间、储藏时间约束，补**动态规划**模型。
3. 官方解析《"蔬菜类商品的自动定价与补货决策"问题解析》（吴萌、张驰、王志勇），2024,13(02):27-36 ——【仅有摘要】命题组可行解法：剥离销量时间效应→揭示分布规律、价格-销量耦合、品类相关；**随机优化（报童模型）**建模求解；成本预测叠加时间效应得最优补货量与售价。命题组关键词明确出现"报童模型"。
4. 同卷其他 C 题获奖论文（题名级线索，未读正文）：《蔬菜类商品动态定价与补货决策研究》《基于贝叶斯模型与 VAR 模型的蔬菜销量与定价预测》《基于价格弹性的蔬菜类商品自动定价与补货决策》（02 期 .06–.08）。

## 方法论特征观察（基于以上已读内容）
- **选题定位差异**：A/B 为机理题，国一思路共性 = "先建可复现的精确评估模型，再降自由度/证结构后做优化"（A 先分解光学效率分量；B 先证明沿等深线/对称性等最优结构）；C 为数据驱动+运营优化，最高奖走"统计检验 → 时序分解（ARIMA/Prophet）→ 随机/启发式优化"。
- **建模风格**：均强调把复杂对象拆成可解释子模型并给出显式公式（余弦/阴影遮挡/截断效率分量、覆盖宽度/重叠率几何递推、销量时间效应与价格效应分离），再叠加求解；避免整题黑箱套用。命题组解析与获奖论文同卷对照，可获知"评阅期望"。
- **优化手段**：真实规模非线性难直接求解时普遍降维/分解：控制变量法+0.618 一维搜索、双层规划循环（A）；数学证明+递推公式、分块+最小二乘（B）；模拟退火+遗传+动态规划（C）。
- **结果与检验**：给明确数值与表格化输出（B：34 条线、总长、漏测率 0 等），A 给出功率-变量试算曲线做灵敏度式说明；期刊精选版公式化、可复现性强。（"评委偏好可复现自洽推导与完整图表规范"属推断，非来源原文。）
